## 首页设备概览与导航留白（2026-11-12）

导航利用主区域剩余高度均匀分布七个入口，关于与设置固定在底部，低窗口保留最小行高。
首页改为总体运行状态与全面体检主操作、设备编号/服务版本/最近检查、三项运行检查及常用入口。
移除无数据依据的守护天数和无法确认的守护进程状态，取消大幅电路插画。
全面体检调用现有 getStatus，分别展示核心响应、连接通道、能力服务；接口不可达时依赖项保持待检查。
页面明确说明病毒扫描、垃圾清理和还原尚未接入体检，未将运行状态检查当成病毒检测。
浏览器回归通过模拟状态响应验证正常、部分异常和离线分支、设备字段及快捷入口；截图来自 Vue 构建页面。
